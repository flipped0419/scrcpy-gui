# Changelog

## v4.1.0-harmony.1 — Preview

- Experimental native HarmonyOS PC Mode through `CastPlusDisplay`.
- Separate stock and Harmony scrcpy-server selection.
- UHID keyboard/mouse defaults for Harmony mode.
- Configurable scrcpy shortcut modifier for releasing UHID mouse capture.
- Shared screen-off, audio, recording, fullscreen and other session behavior settings.
- Low-latency Harmony rendering without the ordinary 100 ms virtual-desktop buffer.
- Lightweight Windows-style UI.
- Deduplicated advanced settings.
- Fixed mouse-wheel/trackpad scrolling.
- Materialized the previously generated customizations into normal repository source files.
